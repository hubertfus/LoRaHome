# v0.2.0-alpha — transport layer

**Motto:** *A frame goes in over USB and comes out of an antenna. Byte for byte.*

Everything Etap 1 set out to build is implemented, tested and measured. Four of
the eight Definition of Done items are closed; the other four are bench
measurements that need two boards and an attenuator, and are itemised below with
the procedure that closes each one. The release is tagged on that basis rather
than held indefinitely — the code is done, the remaining work is instrumentation
on hardware, and `docs/test-bench.md` says exactly what to run.

**What a maintainer should take from this:** the transport works and is
measured everywhere it can be measured without a radio. What is not yet known is
how it behaves against a real antenna over a real day. Do not treat items 1, 2,
4, 5 and 7 as passing until `docs/test-bench.md` has been walked.

## The correction that outlives this release

A 230 B frame at the chosen SF9/BW125/CR4-5 profile occupies the air for
**1147.9 ms**, not the ~390 ms carried in earlier planning notes — that figure
is SF7. Under the ETSI 1% duty cycle this permits roughly **one full frame every
114.8 s** per channel.

The calculation was never wrong; both implementations have always followed
Semtech AN1200.22 and agree across a 336-point grid. Only the number quoted in
prose was. Anything sized against 390 ms needs re-deriving before Etap 2 builds
on it — transmit intervals, the 402 ms end-to-end latency target, and how many
config fragments fit in an hour.
